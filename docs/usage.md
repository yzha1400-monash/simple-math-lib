# 详细使用手册

## API 接口说明

### 1. add(a, b)
- **功能**：返回两个数字的和。
- **示例**：`add(3, 5)` 返回 `8`。

### 2. subtract(a, b)
- **功能**：返回第一个数字减去第二个数字的差。
- **示例**：`subtract(10, 3)` 返回 `7`。

### 3. divide(a, b)
- **功能**：返回第一个数字除以第二个数字的商。
- **⚠️ 警告**：当 `b = 0` 时，程序会抛出 `ValueError` 异常，并提示“除数不能为零”。
- **示例**：`divide(10, 2)` 返回 `5.0`。
