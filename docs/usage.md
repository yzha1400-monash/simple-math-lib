# 📖 详细使用手册

## 🔧 API 接口说明

| 函数 | 功能 | 示例 |
| :--- | :--- | :--- |
| `add(a, b)` | 返回两个数字的和 | `add(3, 5)` → `8` |
| `subtract(a, b)` | 返回第一个数减第二个数 | `subtract(10, 3)` → `7` |
| `divide(a, b)` | 返回两个数的商 | `divide(10, 2)` → `5.0` |

---

## ⚠️ 注意事项

- `divide(a, b)` 中，如果 `b = 0`，程序会抛出 `ValueError` 异常。
- 所有函数均返回 `float`（浮点数）类型。

---

## ❓ 常见问题

**问：为什么除法结果是 3.0 而不是 3？**  
答：因为 Python 的 `/` 运算默认返回浮点数，以保证精度。
