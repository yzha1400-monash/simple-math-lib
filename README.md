---

## 🚀 快速开始

### 1️⃣ 安装依赖

在终端执行：

```bash
pip install -r requirements.txt
2️⃣ 使用示例
创建一个 Python 文件，输入以下代码：

python
from src.calculator import add, divide

print(add(10, 20))   # 输出: 30
print(divide(9, 3))  # 输出: 3.0
🧪 运行测试
确保你在项目根目录下，执行：

bash
python -m pytest -v
如果一切正常，你会看到绿色的 PASSED。
